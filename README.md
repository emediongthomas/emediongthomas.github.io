# Emediong Nsima Thomas — Portfolio

A responsive, no-build portfolio website for Emediong Nsima Thomas. It uses plain HTML, CSS, and JavaScript; no package installation or build step is required.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server. For example, with Python installed:

```powershell
py -m http.server 8000
```

Then visit <http://localhost:8000>.

## Included

- Responsive layout and mobile navigation
- Light/dark theme toggle, saved in the browser when storage is available
- Project filters, contact links, and copy-email button
- Profile portrait in `assets/profile-photo.png`
- Click-to-play AI-generated male voice introduction in `assets/intro-ai.wav`
- Keyboard skip link, focus styles, and reduced-motion support

## Before publishing

- Add a public LinkedIn profile URL if you want it linked; the current LinkedIn link is a placeholder.
- Provide a resume file or public resume URL to add a download link.
- Verify employer dates, project descriptions, and experience metrics.
- The Green Nigeria project is described as a local sandbox; it does not process real transfers.
